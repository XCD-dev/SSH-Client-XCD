# Security policy

## Supported versions

There is no public release yet. Security fixes are being prepared on the
default development branch.

## Reporting a vulnerability

Do not post credentials, exploit details, or an unpatched vulnerability in a
public issue. If private vulnerability reporting is enabled in this GitHub
repository, use **Security → Advisories → Report a vulnerability**. Otherwise,
open a minimal issue asking the maintainers for a private reporting channel;
do not include sensitive details until that channel is available.

This project does not currently publish a security contact email. Do not send
reports to guessed or unrelated addresses.

## Response

The maintainers will acknowledge a private report, reproduce it, assess impact,
and coordinate a fix and disclosure timeline with the reporter. No response
time commitment is made until a maintainer team and reporting channel are in
place.
