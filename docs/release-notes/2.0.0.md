## English

### Highlights

- XCD application name, window title, icon, and logo.
- Switchable light and dark themes, an About dialog, and saved appearance
  preference.
- Sandboxed renderer, restricted renderer navigation, trusted-frame IPC checks,
  and operating-system file-picker uploads.
- First-connection SSH host-key review, symlink checks during SFTP upload, and
  safer handling of remote `sudo` credentials.
- Migration of recognized settings from the previous app data folder without
  deleting or replacing existing files.
- Windows x64, Linux x64, and macOS arm64 packaging targets; bilingual
  user and developer documentation.

### Known limitations

- SSH private-key and agent authentication and SFTP download are not available.
- VPN profile credentials are not protected by the OS keychain.
- Intel Macs are not supported.
- No Windows/macOS signing or macOS notarization is configured.
- Six Moderate audit findings remain in the build-only electron-builder /
  minimatch dependency chain.
- The upstream source collection has not been verified as complete corresponding
  source. Wintun prebuilt-binary redistribution terms require further review.

See [README](../../README.md), [Russian README](../../README.ru.md), and the
[security audit](https://github.com/XCD-dev/SSH-Client-XCD/blob/main/SECURITY_AUDIT.md).

## Русский

### Основные изменения

- Брендинг XCD, название окна, иконка и логотип приложения.
- Светлая и тёмная темы, диалог About и сохранение выбранного оформления.
- Песочница renderer-процесса, ограничение навигации, проверка доверенного IPC
  и загрузка файлов через системный диалог выбора.
- Проверка SSH host key при первом подключении, защита загрузки через SFTP от
  символических ссылок и безопасная передача пароля `sudo`.
- Перенос известных настроек из старого каталога данных без удаления или
  перезаписи файлов.
- Целевые сборки Windows x64, Linux x64 и macOS arm64; документация для
  пользователей и разработчиков на русском и английском.

### Известные ограничения

- Нет аутентификации SSH приватным ключом или через agent и скачивания по SFTP.
- Учётные данные VPN не хранятся в системном хранилище секретов.
- Intel Mac не поддерживается.
- Подпись Windows/macOS и нотариальное заверение macOS не настроены.
- В цепочке сборочных зависимостей electron-builder/minimatch остаются шесть
  Moderate findings.
- Полнота комплекта исходников сторонних компонентов ещё не подтверждена;
  условия распространения бинарного Wintun требуют дополнительной проверки.
