# Terminal

The Terminal view opens an interactive SSH shell. It forwards typed input, terminal resize events, and shell output through the main process. Ctrl+C sends an interrupt to the active remote command. The app also supports running a remote command and displaying its output in the dashboard.

Commands run on the remote server with the connected account's permissions. Review commands before running them, especially commands that delete files, change routes, or install services. Terminal history is kept only for the current app session.
