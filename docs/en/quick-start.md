# Quick start

1. Start the app and enter the SSH host, port, username, and password.
2. On first connection, compare the displayed host key fingerprint with a value obtained through a trusted channel. Accept only if it matches.
3. Use the session list to switch between active servers.
4. Open **Terminal** for an interactive shell or remote commands.
5. Open **File Manager** to browse the remote account. Choose **Upload files** to select local files or folders in the system dialog.

Saved server profiles contain connection metadata but no password. The app currently authenticates with passwords; key files and SSH-agent authentication are not available. See [SSH connections](ssh-connections.md) and [SSH keys](ssh-keys.md).
