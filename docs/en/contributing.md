# Contributing

The original project source is licensed under Apache-2.0. Public binary distribution remains on hold while third-party notices, the sing-box additional name/association term, and Cronet's Chromium-derived license inventory are reviewed. Follow the repository's `CONTRIBUTING.md`, open an issue before substantial changes, and include tests for behavior changes.

For local work, run `npm test` and `npm run lint`. Do not add credentials, private server details, or binary files before their license, source, and notice obligations are reviewed. Do not claim a platform works unless its build and relevant checks passed.
