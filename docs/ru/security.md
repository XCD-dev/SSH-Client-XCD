# Безопасность

## Реализованные меры

- Renderer Electron работает с изоляцией контекста, отключённым Node.js, включённым sandbox, строгой CSP, запрещёнными popup-окнами и навигацией только на страницу приложения.
- Main process отклоняет IPC-вызовы из других окон и фреймов.
- SSH host key проверяется и запоминается; неизвестный или изменённый ключ не принимается молча.
- SSH-пароль хранится в памяти активной сессии и не записывается в профиль сервера.
- Локальные пути загрузки выбираются в системном диалоге. Символические ссылки при загрузке не обходятся.
- Для удалённых команд, которые используют учётные данные, в логи передаются обезличенные подписи операций.

## Ограничения

Аутентификация SSH-ключами и через SSH-agent не реализована. VPN-данные находятся в локальном JSON, а не в системном хранилище секретов. Исходный код проекта лицензирован по Apache-2.0; условия и уведомления для включённых sing-box/Cronet-бинарников ещё проверяются. До устранения этих блокеров публичный релиз запрещён. См. [отчёт аудита безопасности](../../SECURITY_AUDIT.md).
