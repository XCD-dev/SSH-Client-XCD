# Архитектура

Приложение состоит из трёх слоёв Electron:

- `src/main/main.js` управляет окном, проверенными IPC-обработчиками, системными диалогами, подготовкой хранилища и службами.
- `src/main/preload.js` открывает ограниченный интерфейс `sshClient` через `contextBridge`.
- `src/renderer/` содержит HTML, CSS и логику интерфейса. Прямого доступа к Node.js нет.

`src/main/services/sshService.js` управляет SSH-сессиями, проверкой host key, потоками терминала, командами и SFTP. Модули в `src/main/modules/` реализуют серверы, known hosts, файлы, VPN-профили, удалённый VPN и ботов.

Выбор локальных файлов выполняется в main process, чтобы renderer не мог передать произвольный путь. Пользовательские настройки хранятся в каталоге данных Electron; небольшой мигратор копирует известные файлы после ребрендинга.
