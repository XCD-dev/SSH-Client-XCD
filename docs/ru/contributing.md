# Участие в разработке

Исходный код проекта лицензирован по Apache-2.0. Публикация бинарников пока отложена, пока не проверены уведомления о сторонних компонентах, дополнительное условие sing-box об имени и ассоциации, а также лицензии и уведомления Chromium, входящие в Cronet. Следуйте корневому `CONTRIBUTING.md`, перед крупными изменениями сначала создавайте issue и добавляйте тесты для изменения поведения.

Для локальной проверки запускайте `npm test` и `npm run lint`. Не добавляйте пароли, приватные сведения о серверах или бинарные файлы до проверки их лицензий, исходного кода и уведомлений. Не заявляйте поддержку платформы без прошедшей сборки и нужных проверок.
