# Участие в разработке

Исходный код проекта лицензирован по Apache-2.0. Публичные сборки опубликованы в GitHub Releases. Лицензии компонентов и результаты проверки указаны в корневом файле `THIRD_PARTY_NOTICES.md`. Следуйте корневому `CONTRIBUTING.md`, перед крупными изменениями сначала создавайте issue и добавляйте тесты для изменения поведения.

Для локальной проверки запускайте `npm test` и `npm run lint`. Не добавляйте пароли, приватные сведения о серверах или бинарные файлы до проверки их лицензий, исходного кода и уведомлений. Не заявляйте поддержку платформы без прошедшей сборки и нужных проверок.
