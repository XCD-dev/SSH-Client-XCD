# Устранение проблем

- **Host key изменился:** остановитесь и проверьте новый отпечаток через доверенный канал. Причина может быть в переустановке сервера или MITM-атаке.
- **Сервер отклоняет пароль:** проверьте адрес, порт, имя пользователя, пароль и настройки парольной аутентификации SSH. SSH-ключи эта версия не поддерживает.
- **Не удаётся загрузить файл:** проверьте права записи и свободное место. Символические ссылки не загружаются; соединение SFTP должно оставаться активным.
- **Не работает предпросмотр:** поддерживаются только обычные текстовые файлы размером до 256 КБ.
- **Не найден VPN engine:** проверьте блок статуса engine. Если bundled-версия недоступна, приложение может использовать `sing-box` из `PATH`; поддержка зависит от ОС и архитектуры.
- **Ошибка сборки:** выполните `npm ci`, проверьте требования текущей ОС и сохраните полный вывод ошибки. Четыре целевые конфигурации пока не все проверены.
