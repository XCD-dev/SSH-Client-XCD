# Установка

XCD SSH Client 2.0.0 пока не опубликован для скачивания. Исходный код проекта лицензирован по Apache-2.0; лицензии и уведомления для включённых sing-box/Cronet-бинарников и кросс-платформенные проверки ещё не завершены. Не распространяйте сборки из этого исходного дерева.

## Запуск из исходников

1. Установите Node.js 22.12 или новее и npm.
2. Склонируйте или скачайте исходный код.
3. В корневой папке выполните `npm ci`.
4. Запустите `npm start`.

Сборки сгруппированы по Windows, Linux и macOS, чтобы их было удобнее скачивать. Подпись и нотариальное заверение для macOS и Windows не настроены. Инструкции по созданию сборок — в разделе [Сборка](building.md).
