# Быстрый старт

1. Запустите приложение и введите адрес SSH-сервера, порт, имя пользователя и пароль.
2. При первом подключении сравните показанный отпечаток host key со значением из доверенного канала. Принимайте его только при совпадении.
3. Переключайтесь между активными серверами в списке сессий.
4. Откройте **Terminal**, чтобы работать в интерактивной оболочке или запускать удалённые команды.
5. В **File Manager** просматривайте файлы удалённого пользователя. Нажмите **Upload files**, чтобы выбрать локальные файлы или папки в системном диалоге.

В сохранённом профиле есть параметры подключения, но нет пароля. Сейчас доступны только пароли; ключи и SSH-agent не поддерживаются. См. [SSH-подключения](ssh-connections.md) и [SSH-ключи](ssh-keys.md).
