# SSH-ключи

В этой версии нет аутентификации приватным SSH-ключом и поддержки SSH-agent. Форма подключения принимает только пароль.

Не вставляйте приватный ключ в терминал, команду бота или профиль сервера. Диалог загрузки файлов предназначен для файлов, которые пользователь явно выбрал для передачи; он не используется для SSH-аутентификации.

Пока используйте учётную запись с разрешённой парольной аутентификацией и соблюдайте правила доступа сервера. Поддержку ключей следует добавлять вместе с обработкой passphrase, SSH-agent и тестами на целевых платформах.
