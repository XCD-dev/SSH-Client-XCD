# SSH-подключения

Введите имя хоста или IP-адрес, порт (по умолчанию 22), имя пользователя и пароль. Подключение создаётся в main process через библиотеку `ssh2`.

## Проверка host key

При первом подключении приложение показывает отпечаток SSH-ключа сервера. Проверьте его независимо, прежде чем доверять ему. Отпечаток сохраняется локально. При изменении ключа показывается предупреждение и требуется отдельное решение; неожиданный ключ принимать нельзя.

## Сохранённые серверы и сессии

Профиль содержит название, хост, порт, имя пользователя и временные метки. Пароли не сохраняются. Пока сессия активна, пароль остаётся в памяти для автоматического переподключения после сетевого сбоя; при закрытии сессии он очищается. Можно держать несколько сессий открытыми одновременно.

Приватные ключи и SSH-agent пока не поддерживаются. См. [SSH-ключи](ssh-keys.md).
