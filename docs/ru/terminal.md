# Терминал

В разделе Terminal открывается интерактивная SSH-оболочка. Приложение передаёт ввод, изменение размера терминала и вывод оболочки через main process. Ctrl+C отправляет прерывание активной удалённой команде. Также можно запускать удалённые команды и показывать их вывод в панели.

Команды выполняются на сервере с правами подключённой учётной записи. Проверяйте команды перед запуском, особенно команды удаления файлов, изменения маршрутов и установки служб. История терминала хранится только в текущем сеансе приложения.
