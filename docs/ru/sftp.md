# Файловый менеджер SFTP

Файловый менеджер использует SFTP через активное SSH-соединение. Он умеет показывать содержимое каталогов, создавать файлы и папки, предварительно просматривать обычные текстовые файлы до 256 КБ, удалять выбранный удалённый элемент после подтверждения и загружать локальные файлы или папки.

## Загрузка

Нажмите **Upload files**, чтобы открыть системный диалог выбора файлов. Renderer не может передать произвольный локальный путь. Символические ссылки в локальных папках пропускаются с ошибкой; загрузка через удалённую символическую ссылку запрещена. Приложение проверяет целевой элемент верхнего уровня и спрашивает перед заменой. При подтверждённой замене папки совпадающие вложенные файлы могут быть перезаписаны.

Сейчас интерфейс не скачивает удалённые файлы на компьютер. Большие файлы нельзя предварительно просматривать. Операции также зависят от прав пользователя и возможностей SFTP-сервера.
