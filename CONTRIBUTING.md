# Contributing

Thanks for your interest in XCD SSH Client. Read the project status and the
English [contribution guide](docs/en/contributing.md) before opening a pull
request. The Russian guide is at [docs/ru/contributing.md](docs/ru/contributing.md).

The original project source is licensed under Apache-2.0. Public binary
distribution remains on hold while the maintainers review third-party notices,
the sing-box additional name/association term, and Cronet's Chromium-derived
license inventory. Do not redistribute bundled binaries until that review is
complete. Open issues and pull requests for source changes are welcome.
