# Code of Conduct

## Our standard

We aim to keep participation in XCD SSH Client respectful and constructive.
Examples of expected behavior include welcoming different viewpoints, giving
useful and specific feedback, and focusing criticism on ideas and code rather
than people.

Unacceptable behavior includes harassment, discrimination, personal attacks,
threats, publishing private information, and deliberately disruptive conduct.

## Scope and enforcement

This standard applies in project spaces and when someone represents the
project. Project maintainers may remove content or restrict participation in
response to behavior that harms the community.

To report a concern, use GitHub's private reporting channel when available. If
it is unavailable, open a minimal issue requesting private contact and do not
publish sensitive details. There is no dedicated response team yet.

This short policy is adapted from the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
